Nearmap Review

Delivery

Vendor polygons live in ai/original/regions.json and never change. Save writes the working set to ai/edits/regions.json (S3 via the sheet, or the local file). Revert changes discards paint since the last Save (or since you opened). Revert to original puts the vendor file back.

Pins editor. Regions are read-only (finish them in the Regions editor). Auto Generate Pins places one pin per region at its interior point, named after the region class in regions.json (Lawn Grass stays Lawn Grass — not a catalog entry). Cover/veg classes are skipped (asphalt, building deprecated, concrete slab, driveway, vegetation, natural, roof, translucent roofing, water body, woody). No cap. Place pin: turn on a layer, then click a painted region that has no pin — the pin is placed at that region's interior point, not at the click. Delete pin: click a painted region that has a pin, or the pin itself — the region stays. Bare map clicks do nothing. Save writes the Nearmap sheet.
