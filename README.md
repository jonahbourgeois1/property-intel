# property-intel

Responder-facing property intelligence viewers for Vyanet, served by GitHub Pages at **responder-intel.vyanet.com**. This repo holds the static HTML viewers and the published per-property JSON records (`data/`). The imagery pipeline that feeds it lives in a separate private repo (`property-intel-v2`); a Google Apps Script project orchestrates both and is the only writer to `data/`.

## What's here

- `element-review.html` — analyst QA tool for AI-placed element pins (Google Maps satellite basemap) + `nadir-geo.js` (its geometry module)
- `model-viewer.html` — interactive 3D property viewer with camera pins and live video/clips
- `viewer.html`, `responder-intel.html`, `hoa-viewer.html`, `plane-viewer.html`, `plane-test.html` — property/HOA/capture views
- `data/` — published records (index, satellite, plane, drone, drone-test, hoa), parcel tiles, pin catalogs. **Machine-written by the Apps Script sync — do not hand-edit; edits are overwritten on the next sync.**
- `lambda/` — reference copies of pipeline Lambda code. **Stale by design; the deployed source lives in the pipeline repo. Never deploy from here.**
- `config.js` — generated by `.github/workflows/build.yml` from a repo secret on every push. Never hand-edit.

## Quick start

```
python3 -m http.server 8899
# then: http://localhost:8899/viewer.html?property=<hash from data/index/>
# or:   http://localhost:8899/model-viewer.html?property=83af9960667d769f621a4a70ad03a970&view=drone-test&debug=1
```

No build step. Heavy assets (tiles, 3D models, renders) load from CloudFront; live video loads through a gateway (passcode-gated). Production testing happens against the live Pages site.
